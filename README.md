## 👨‍💻 About me

I'm a **SQL Server Specialist** with over 8 years of hands-on experience in database administration, query optimization, and backend data solutions, primarily within complex retail ERP environments such as **Linx Sistemas**.

My technical background includes advanced SQL Server training at Impacta, under Prof. Landry Duailibe, combined with practical experience in execution plan analysis, indexing strategies, troubleshooting, and critical bottleneck resolution.

I'm currently expanding my stack with **C# and .NET**, **Python**, and **Artificial Intelligence**, connecting database expertise with backend development, data analysis, automation, and intelligent solutions.

- 🔭 **Current focus:** Preparing for the **DP-300** and **DP-900** Microsoft certifications.
- 🛠️ **Building:** A SQL Server monitoring tool focused on performance and observability for DBAs.
- 🐍 **Python:** Learning scripting, data processing, database integration, and task automation.
- 🤖 **Artificial Intelligence:** Exploring generative AI, prompt engineering, AI-assisted development, and practical data applications.
- 📚 **Backend:** Studying C#, OOP, LINQ, Dapper, Entity Framework Core, and API development.
- ⚡ **Interests:** Query tuning, execution plans, indexing, automation, data engineering, and intelligent systems.
